# اختبار ملف Excel

`public/assets/projects/financial-model-test.xlsx`

`assets/projects/financial-model-test.xlsx`

ضع هذا المسار في حقل **Additional Model Media URLs** كسطر مستقل، ثم احفظ المشروع.

- روابط ملفات المشاريع أصبحت عامة (External Files) بدل ربطها بخدمة واحدة.
